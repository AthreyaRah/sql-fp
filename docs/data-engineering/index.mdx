# Data Engineering

SQL as the transformation layer in a warehouse. Here the database isn't serving
one row to one user — it's rebuilding wide tables from source data on a schedule,
and the questions are about *grain*, *history*, and *idempotency* rather than
latency.

This track assumes [Foundations](/foundations/) — especially
[joins](/foundations/inner-join), [`GROUP BY`](/foundations/group-by-and-aggregation),
[window functions](/foundations/window-functions-partitioning-and-ranking), and
[`MERGE`](/foundations/upsert-and-merge). It is being built out; the two pages
below are complete and set the format.

## Topics

1. [Dimensional modeling: the star schema](/data-engineering/dimensional-modeling-star-schema)
