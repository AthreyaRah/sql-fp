# SQL from First Principles

Most SQL material teaches you syntax and hopes the model sticks. This teaches the
**model first** — what a relation actually is, what the query engine does with
your `SELECT`, why `NULL` breaks your `NOT IN`, what a B-tree buys you — and only
then the syntax, which by that point is obvious.

It is the sibling of
[Python from First Principles](https://github.com/AthreyaRah/python-fp), built the
same way: every claim is backed by a script that runs in CI, and every "this
breaks" is a script that really breaks.

## The three tracks — 71 topics

- **[Foundations](/foundations/)** (41) — the SQL common core, in dependency
  order: the relational model, `NULL` & three-valued logic, joins, aggregation,
  subqueries, CTEs, window functions, transactions, isolation & MVCC, indexes,
  reading query plans and optimization — then dates & time zones, text & regex,
  JSON/JSONB, arrays, `LATERAL`, triggers, roles & RLS, bulk loading, and money
  arithmetic. Work top to bottom the first time.
- **[Backend Engineering](/backend/)** (15) — SQL as the storage layer behind an
  API: keyset pagination & N+1, `EXPLAIN`-driven optimization, normalization,
  keys, relationship modeling, soft deletes & audit, optimistic/pessimistic
  locking, write skew, JSONB & full-text search, enums vs lookup tables, safe
  online migrations, idempotency keys, connection pooling.
- **[Data Engineering](/data-engineering/)** (15) — SQL as the transformation
  layer in a warehouse: OLTP vs OLAP, dimensional modeling, grain & additivity,
  every SCD type, incremental loads & watermarks, deduplication & data quality,
  sessionization, pivot/unpivot, the date dimension, rollup tables, bridge
  tables, late-arriving data, partitioning, BRIN.

## Why PostgreSQL

Everything targets **PostgreSQL** (the in-page engine is Postgres 16+; CI runs
every script on a stock Postgres 16). The concepts are standard SQL; Postgres
just has the clearest `EXPLAIN`, the fullest window-function and `MERGE` support,
and `GIN`/`BRIN`/partitioning for the later topics. If you use MySQL or SQLite,
95% transfers — the pages call out where it doesn't.
